
# 자료구조 (Data Structure)

## 1. 배열 (Array)

- 각 요소에 인덱스를 통해 직접 접근할 수 있다.
- 요소 삽입 및 삭제 시 해당 위치 이후의 요소들을 이동해야 한다.
- 특정 값을 검색할 때는 일반적으로 배열의 처음부터 순차적으로 탐색한다.

### 시간복잡도
- 인덱스를 통한 요소 접근: O(1)
- 요소 추가: O(1)* 
- 요소 삽입 및 삭제: O(n)
- 특정 값 검색: O(n)

## 2. 연결 리스트 (Linked List)

- 노드(Node)로 구성된 자료구조이다.
- 각 노드는 데이터와 다음 노드를 가리키는 포인터를 가지고 있다.
- 양방향 연결 리스트의 경우 이전 노드를 가리키는 포인터도 가진다.
- 첫 번째 노드를 Head, 마지막 노드를 Tail이라고 한다.
- 특정 노드에 접근하려면 Head부터 순차적으로 탐색해야 한다.
- 삽입 시 새로운 노드를 생성하고 주변 노드의 포인터를 수정한다.
- 삭제 시 주변 노드의 포인터를 수정하고 해당 노드를 제거한다.

### 시간복잡도
- 특정 위치의 요소 접근: O(n)
- 노드 삽입 및 삭제: O(1)*
- 특정 값 검색: O(n)

## 3. 스택 (Stack)

- 후입선출(LIFO, Last In First Out)의 특성을 가진 자료구조이다.
- 새로운 요소는 가장 마지막 위치에 추가된다.
- 요소를 꺼낼 때도 가장 마지막에 추가된 요소부터 사용한다.

### 시간복잡도
- 요소 접근(Peek): O(1)
- 삽입(Push): O(1)
- 삭제(Pop): O(1)

## 4. 큐 (Queue)

- 선입선출(FIFO, First In First Out)의 특성을 가진 자료구조이다.
- 새로운 요소는 가장 마지막 위치에 추가된다.
- 요소를 꺼낼 때는 가장 먼저 추가된 요소부터 사용한다.

### 시간복잡도
- 요소 접근(Peek): O(1)
- 삽입(Enqueue): O(1)
- 삭제(Dequeue): O(1)*

## 5. 트리 (Tree)

- 노드와 간선으로 구성된 계층적인 자료구조이다.
- 대표적인 형태로 이진트리(Binary Tree)가 있다.
- 배열로 구현한 완전 이진트리의 경우 일반적으로 인덱스 0을 비우고 1부터 사용한다.
- 부모 노드의 인덱스는 해당 노드 인덱스를 2로 나눈 몫이다.
- 왼쪽 자식 노드는 부모 인덱스 * 2, 오른쪽 자식 노드는 부모 인덱스 * 2 + 1로 접근한다.

### 시간복잡도
- 요소 검색: 평균 O(log n), 최악 O(n)
- 요소 삽입: 평균 O(log n), 최악 O(n)
- 요소 삭제: 평균 O(log n), 최악 O(n)

## 6. 그래프 (Graph)

- 정점(Vertex)과 간선(Edge)으로 구성된 자료구조이다.
- 정점 간의 연결 관계를 표현한다.
- 트리와 달리 부모와 자식의 계층 관계가 반드시 존재하지 않는다.
- 방향 그래프와 무방향 그래프로 구분할 수 있다.
