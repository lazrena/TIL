
# 자료구조 (Data Structure)

## 1. 자료구조란?
- 데이터를 저장, 제거, 조작하는 방법을 정의한 것.

## 2. 자료구조의 목적과 필요성
- 각 데이터의 상황에 맞춰 자료구조를 선택함으로써 효율적인 데이터 관리가 가능하다.

## 3. 자료구조의 종류와 분류
- 단순 자료구조에는 int, double, float, string 등이 있고, 복합 자료구조에는 선형 자료구조와 비선형 자료구조가 있다.
- 선형 자료구조에는 배열, 연결 리스트, 스택, 큐, 해시 테이블이 있다. [보완 필요]
- 비선형 자료구조에는 트리, 그래프가 있다.

## 4. 추상 자료형 (ADT)
- 코드로 직접 구현한 구현체가 아닌, 해당 자료구조의 정의와 특성만을 나타낸 것. [보완 필요]

## 5. 자료구조와 알고리즘의 관계
- 문제를 해결하는 방법을 표현한 것이 알고리즘이다.
- 효율적인 문제 해결을 위해서는 먼저 주어진 데이터를 효율적으로 사용할 수 있도록 바꿔야 한다. [보완 필요]

## 6. 자료구조별 메모리 구조와 저장 방식
- 배열은 크기가 정해져 있기 때문에 해당 크기의 공간을 메모리의 연속적인 주소에 할당한다.
- 하지만 똑같은 선형 구조인 연결 리스트는 각 노드가 다음 노드의 주소를 알고 있기 때문에 노드의 주소가 꼭 연속적이지 않아도 된다.
- 노드의 추가와 삭제가 자유롭기 때문에 메모리의 연속적인 주소에 할당되지 않는다.
